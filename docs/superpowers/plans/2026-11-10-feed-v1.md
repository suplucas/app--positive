### Task 2 — `collapseNotifications` (função pura)

- **Arquivos:** create `src/application/service/collapseNotifications.ts` +
  `collapseNotifications.spec.ts`
- **Assinatura:**
  ```ts
  export type NotificationRow = {
    id: number;
    type: string;
    actorId: string | null;
    reviewId: number | null;
    restaurantId: string | null;
    readAt: Date | null;
    createdAt: Date;
    previewText?: string | null;
  };

  // Linha colapsada: agrupa likes por review e saves por restaurante.
  export type CollapsedNotification = NotificationRow & {
    ids: number[];        // todos os ids crus do grupo (ordem de entrada)
    actors: string[];     // actorIds distintos, não-nulos, em ordem
    count: number;        // nº de linhas colapsadas
  };

  export function collapseNotifications(
    rows: NotificationRow[],
  ): CollapsedNotification[];
  ```
- **Regras (spec 6.5/7.4):**
  - Entrada vem ordenada por `createdAt DESC` (a primeira linha é a mais
    recente). Grupos mantêm essa posição na saída.
  - `like` agrupa por `reviewId` (chave `like:{reviewId}`); **sem `reviewId`
    (null), cada linha fica individual** (chave única por id).
  - `save` agrupa por `restaurantId` (chave `save:{restaurantId}`); null
    `restaurantId` → individual.
  - `comment`, `follow`, `network_visit`, `milestone` → sempre individuais
    (`ids: [id]`, `actors` derivado, `count: 1`).
  - Merge do grupo: `id` = id da primeira linha; `ids` = todos; `actors` =
    actorIds distintos não-nulos em ordem; `count` = linhas; `readAt = null`
    se **qualquer** linha for não-lida, senão o `readAt` da primeira;
    `createdAt` = da primeira (mais recente); `previewText` = primeiro
    não-null; `actorId`/`reviewId`/`restaurantId` = o valor da chave do grupo.
- **Passos (TDD):** spec cobre: likes agrupam por review; saves agrupam por
  restaurante; merge de `ids`/`actors`/`count`; `readAt` null quando alguma
  linha não-lida; tipo sem grupo fica individual; like sem reviewId fica
  individual; ordem preservada (grupo na posição da linha mais recente).
- **Verificação:** `npx vitest run src/application/service/collapseNotifications.spec.ts` verde.
- **Commit:** `collapseNotifications: agrupa likes/saves em leitura`
